Design

exec is a small Spring Boot service that takes code, language and stdin, runs it inside a short-lived, locked-down Docker container, and returns stdout, stderr, the exit code and how long it took.

High Level Design

Overview

Both endpoints live under /api/v1. Requests and responses are JSON. There is no login, and CORS allows every origin on /api/**.

MethodPathPurpose
GET/api/v1/languagesList the supported languages
POST/api/v1/executeRun code and return its output

API contract

GET/api/v1/languages

Returns every supported language. Use these exact values in POST /api/v1/execute.

Response · 200 OK
{
  "availableLanguages": ["PYTHON", "JAVASCRIPT", "JAVA", "C", "CPP"]
}

POST/api/v1/execute

Runs the code in a sandboxed container and returns what it printed. The HTTP status is 200 whenever the code ran, even if the program crashed or timed out; check status in the body.

Request body
FieldTypeRequiredRules
languagestringYesOne of PYTHON, JAVASCRIPT, JAVA, C, CPP (uppercase)
codestringYesNot blank, at most 100,000 characters
stdinstringNoAt most 10,000 characters; sent to the program's standard input
 
{
  "language": "PYTHON",
  "code": "name = input()\nprint(f\"Hello, {name}!\")",
  "stdin": "Ada"
}
Response body · 200 OK
FieldTypeMeaning
statusstringSUCCESS, ERROR or TIMEOUT
stdoutstringStandard output, capped at 1 MB
stderrstringStandard error, including compile errors. On timeout it holds the timeout message.
exitCodeinteger | nullProcess exit code; null on timeout
executionTimeMsintegerWall-clock time in ms, including container start and compiling
statusWhenexitCode
SUCCESSProgram finished with exit code 00
ERRORNon-zero exit code (runtime error, failed compile, exit(1), out of memory…)non-zero
TIMEOUTStill running after 10 seconds; killednull
Examples
// SUCCESS
{ "status": "SUCCESS", "stdout": "Hello, Ada!\n", "stderr": "", "exitCode": 0, "executionTimeMs": 412 }

// ERROR
{ "status": "ERROR", "stdout": "",
  "stderr": "Traceback (most recent call last):\n  ...\nZeroDivisionError: division by zero\n",
  "exitCode": 1, "executionTimeMs": 398 }

// TIMEOUT
{ "status": "TIMEOUT", "stdout": "",
  "stderr": "Execution timed out after 10 seconds",
  "exitCode": null, "executionTimeMs": 10004 }
curl
curl -X POST http://localhost:8080/api/v1/execute \
  -H "Content-Type: application/json" \
  -d '{"language":"PYTHON","code":"print(1 + 1)"}'

Limits & sandbox

10 sMax run time, including compiling
1 MBPer stream (stdout, stderr); the rest is cut with a "[output truncated]" note
100,000 charsMax code size
10,000 charsMax stdin size
